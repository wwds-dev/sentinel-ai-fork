# Quick Start

**Goal:** complete a safe first request. **Time:** about five minutes.

![Sentinel Chat workspace](docs/training/images/workspace-chat.png)

1. Choose **Chat** in the left sidebar.
2. Select **General Chat** and type a simple question.
3. Press **Auto-route** to see the recommended provider and model.
4. Check the route before sending. Ollama is local; amber selections use a
   cloud provider and may cost money.
5. Press **Enter** to send. Use **Shift+Enter** when you want a new line.
6. Read the answer in the scrollable conversation. Each message has a local
   date and time.
7. Open **Inspector** if you want to review route, cost, budget or system use.

## What each area does

The left side selects an agent and opens saved work. The centre contains the
current agent's inputs and results. The optional Inspector on the right shows
the active route, recorded cost, budgets and device load. **Agent guide** opens
technical reference for the selected agent; **Learning centre** provides these
step-by-step lessons.

## Best practice

Start locally when a task contains private information. Before allowing a
cloud request, review exactly what will leave the device. A recommendation is
still a choice: you can change it before running the task.

## Completion check

You can identify the selected provider, tell whether it is local or cloud,
send a message, and find the resulting cost information.
